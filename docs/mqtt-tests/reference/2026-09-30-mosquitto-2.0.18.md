## Broker limitations found

- **MTLS-08 FAIL**: No revocation check is active (CRL, OCSP or registry lookup). Revocation strategy is OPEN (ENTC-58/ENTC-31); for Mosquitto `crlfile certs/negative/crl.pem` makes this case pass.
- **ID-01 FAIL**: The broker accepts a Client ID that differs from the certificate identity and lets it displace the legitimate session. EICP v1.4 requires Client ID == Gateway ID; enforcement must come from the broker (classify NATIVE / CONFIGURATION / PLUGIN / CUSTOM for ENTC-59).
- **DUP-01 FAIL**: The broker applies the MQTT session takeover. ENETEC requires rejecting the second connection and keeping the active session (ENETEC.md §6.3); needs broker support or an extension.
- **ACL-08 PARTIAL, ACL-09 PARTIAL, ACL-10 PARTIAL, ACL-11 PARTIAL, ACL-12 PARTIAL, ACL-13 PARTIAL**: The broker grants the SUBSCRIBE (SUBACK < 128) and filters on delivery: isolation holds, but the denial is not signalled to the client and a denied subscription is not visible as such.
